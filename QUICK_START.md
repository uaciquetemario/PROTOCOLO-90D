## 🎯 5 PASSOS PARA COMEÇAR

### PASSO 1: Criar Repositório (2 min)
1. Vá para [github.com/new](https://github.com/new)
2. Nome: `90-dias-mudanca-vida`
3. Descrição: "Protocolo 90D - Transformação pessoal"
4. Clique: Create

### PASSO 2: Fazer Upload dos Arquivos (3 min)
Clique em **Add file** → **Upload files**
- Suba: `README.md`, `PROTOCOLO.md`, `TEMPLATES.md`, `GITHUB_SETUP.md`

### PASSO 3: Criar Estrutura (2 min)
Pelo GitHub, clique **Add file** → **Create new file**:
- `metas/Ciclo_1_Metas.md`
- `days/Day_01.md`
- `reviews/Week_1_Review.md`
- `statistics/stats.json`

### PASSO 4: Preencher Dia 1 (2 min)
Abra `days/Day_01.md` e copie este template:

```markdown
# Dia 01 - [Data de hoje]
Ciclo: 1 | Semana: 1 | Streak: 🔥 1

## ✅ CHECKLIST DO DIA

### 💪 SAÚDE
- [ ] Exercício - Tipo: caminhada 30min
- [ ] Sono 8h
- [ ] 2L de água
- [ ] Nutrição

### 💰 FINANÇAS
- [ ] Registrar gastos
- [ ] Zero impulsivos
- [ ] Ação: pesquisar renda extra

### 🧘 ESPIRITUALIDADE
- [ ] Meditação 10min
- [ ] Journal 5min

### 💬 RELACIONAMENTOS
- [ ] 1 comunicação genuína
- [ ] 1 ato de generosidade

### 🧠 DESENVOLVIMENTO
- [ ] Estudo 1h
- [ ] Prática

## TOTAL DO DIA: __/120 pts

## 📝 REFLEXÃO
O que correu bem? Meus desafios? Aprendizado?
```

## 💡 HACKS PARA SUCESSO

### ✨ Dia Perfeito = 120 pontos
Não precisa de 120 todo dia. Média de 100 já é excelente!

### 🔥 Streak é Motivador
- 7 dias sem falhar: +20 bônus
- 14 dias: +30 bônus
- 30 dias: +50 bônus

### 📱 Use Smartphone
- Foto semanal de progresso
- Alarmes para metas (exercício, meditação, estudo)
- App de hábitos paralelo (opcional)

### 📚 Mantenha Simples
Primeira semana: execute. Não perfeito.
Segunda semana: refine.
Terceira semana: domina.

### 🎯 Customize Metas
Se ficou fácil: aumenta.
Se ficou impossível: reduz.
Não há "certo", há seu ritmo.
